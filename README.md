# 潮汐之间

安装：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`；生产构建：`npm run build`。

Docker 启动：`docker compose up --build`，访问 http://localhost:8133 。

## 全景故事明信片

在「探索手记」里勾选几条记录 →「制作全景明信片」，即可生成一个可离线打开的独立 HTML 文件。

- **取景**：卡片画面由保存的镜头（方位 / 俯仰 / 视场）在 CPU 上按同一投影直接重绘，不截界面，也不包含按钮与浮层。
- **构图来源**：制作开始时可以选择「制作开始时的构图」或「最近一次确认的构图」；在场景上方按「记下这个构图」即可确认最新视角。制作过程中可以继续转镜头、写手记。
- **宽窄屏**：每张卡片可单独切换宽屏 / 窄屏预览，人物与热点标记按投影方向重新定位；热点落到画面外时会贴边并标注方位，不会丢失对应关系。
- **画质**：轻量 / 平衡 / 完整细节三档，会按设备纹理上限收敛并向用户说明；可先试渲染再决定。
- **控制**：可停止后续任务；已完成的卡片能单独保存，失败项可重试；迟到的旧渲染结果会被丢弃。
- **返回线索**：每张卡片带有 `#return=…` 链接，回到影片时会恢复章节、时间与镜头。
